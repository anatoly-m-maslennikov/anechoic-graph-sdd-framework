# Codex native support only

ANECHOIC's current native LLM-application support set **contains** Codex **and** no other application. Native support **means** that ANECHOIC owns **and** maintains the application adapter required **to** install **and** invoke framework interfaces **and** resolve host-session identity **without** an Extension **or** operator-provided compatibility layer. **every** other LLM application remains outside native support **until** an applicable active Boundary Requirement expands **or** replaces this Boundary.
