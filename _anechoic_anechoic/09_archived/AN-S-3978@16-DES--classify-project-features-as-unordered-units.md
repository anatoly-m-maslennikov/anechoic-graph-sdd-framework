# Classify Project Features as unordered units

**every** ANECHOIC Feature is an `unordered_unit`, is owned by **=1** immediate Structural unit, **and** has no `local_order`. a Feature owned directly by ANECHOIC is at Structural level `1`; a Layer-owned Feature is at Structural level `2`.
