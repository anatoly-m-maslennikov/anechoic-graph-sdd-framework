# Derive FPF behavior from current ANECHOIC authority

Within a ANECHOIC Project, FPF **must** resolve its routing, terminology, Atom classification, authority boundary, Scope Unit ownership, lifecycle, **and** validation behavior from the current Applicable Methodology **and** Project Configuration, **and** **must not** substitute FPF-native conventions, remembered chat decisions, generated reports, **or** Skill prose for ANECHOIC authority.
