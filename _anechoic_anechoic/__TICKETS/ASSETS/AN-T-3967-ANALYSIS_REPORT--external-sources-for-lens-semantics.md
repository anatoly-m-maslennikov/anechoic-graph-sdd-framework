## Summary

External sources for Lens semantics

## Sources

- [ISO/IEC/IEEE 42010:2022](https://www.iso.org/standard/74393.html) describes architecture descriptions, viewpoints, and model kinds. It informs the Lens grouping and DES.
- [ISO/IEC 21838-1:2021](https://www.iso.org/standard/71954.html) addresses top-level ontologies and their relation to domain ontologies. It informs DOM/ONT.
- [ISO/IEC 24744:2014](https://www.iso.org/standard/62644.html) describes a metamodel for development methodologies. It informs DOM/MTD and DES/DOM.
- [The Open Group, TOGAF Standard, 10th Edition](https://help.opengroup.org/hc/en-us/articles/32726995273362-Understanding-the-TOGAF-Standard) provides a framework and methods for Enterprise Architecture. It informs DES and the use of defined methods in DOM/MTD.
- [ISO/IEC/IEEE 12207:2026](https://www.iso.org/standard/90219.html) describes software life cycle processes. It informs SWD and DevOps.
- [ISO/IEC/IEEE 29119-2:2021](https://www.iso.org/standard/79428.html) describes software test processes. It informs the testing part of QA.
- [ISO/IEC 24707:2018](https://www.iso.org/standard/66249.html) gives an example of formal representation with declarative semantics. It informs SPEC.
- [ISO/IEC 9075-2:2023](https://www.iso.org/standard/76584.html) addresses SQL fundamentals. [dbt project structure guidance](https://docs.getdbt.com/best-practices/how-we-structure/1-guide-overview) describes staging, intermediate models, and marts. They inform SWD/DBT.

## Scope

The Lens names, scopes, and axis presets are ANECHOIC definitions informed by these sources.
