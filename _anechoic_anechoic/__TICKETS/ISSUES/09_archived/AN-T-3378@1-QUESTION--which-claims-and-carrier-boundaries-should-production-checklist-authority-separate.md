# Which Claims and Carrier boundaries should production checklist authority separate?

which independently replaceable Claims **must** replace ANECHOIC-GOV-REQU-314, **and** which Evaluation Control information belongs **to** semantic requirements rather than a separately specified Carrier?

## Evidence

ANECHOIC-GOV-REQU-314 combines production-readiness eligibility, the information required of an Evaluation Control, the definition of Production Evaluation Checklist as a Catalog Projection, **and** separation of definitions, realizations, **and** factual execution records. its Projection Content Role **and** Operations-record classification errors have been corrected, but that correction does **not** resolve the mixed Claim boundary **or** certify its generic `evaluation` Subject.

the ten required control-information items include the checked authority, signal source, acceptance condition, cadence **and** detection delay, applicability, accountable owner **and** escalation, failure response, diagnostic context, factual records **and** retention, **and** known limitations. no concrete field encoding **or** template is selected here. ANECHOIC-GOV-REQU-748 admits the Evaluation Control Type; ANECHOIC-GOV-REQU-313 owns Catalog as a Projection Type; CA-D-400 owns Type token serialization. retain those existing owners.

## Principle check

CA-M-002 rejects duplicate authority; CA-M-006 requires consistent classification; CA-M-005 rejects invented Properties **or** schemas; CA-R-1490 preserves the complete control information. CA-R-1270 **and** CA-R-1432 require independently replaceable Claims **to** receive separate identities. CA-C-123 already records the semantic-information versus Carrier-content boundary; this case adds production-specific ownership **and** dependency impacts.

## Disposition

defer the split under the Operator's uncertainty policy. retain the corrected source **and** its exact predecessor. establish the separate Claim owners, qualified governed targets, **and** exact incoming-reference mapping **before** replacement. preserve **all** control information **and** production-readiness conditions; do **not** impose a telemetry format, move production logs into the Project Journal, close the open Evaluation Type domain, **or** allow a Projection **to** become authority. this Concern does **not** certify the remaining bundled Claims.
