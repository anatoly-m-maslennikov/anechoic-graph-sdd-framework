## Summary

Consolidate obsolete Graph UI specification into Workbench

## Details

Three read-only reviews agree that the separate Graph UI application is obsolete. Preserve keyboard operability and inert rendering in the existing Workbench UI Requirement and its Evaluation. Other generic state/interface constraints already have Workbench coverage. The old standalone HTML graph browser, its carriers and its scope should retire; no new graph feature is introduced. Receiver Drafts and retirement/reference checks are in progress.
