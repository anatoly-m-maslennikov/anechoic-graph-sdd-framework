## Summary

Declare Relation endpoints

## Claim

### Prose Claim

Begin each Relation name with a verb. Each canonical Relation and each qualified derived Relation has one Active Formal Manifest.

Declare the eligible endpoint kinds and levels. An endpoint is a declared Model entity or instance. Resolve names exactly. A literal value cannot be a graph endpoint. The matched endpoint pair admits the link. Apply the bearer’s additional restrictions and cardinalities. Report unresolved endpoints.

The canonical Manifest owns its meaning and inverse alias. An inverse reverses endpoints and their cardinality slots while representing the same fact. Reject self-pairs, aliases with multiple canonical sources, or conflicting names. A qualified derived Relation declares its source, endpoint transformation, and qualification.

Apply a declared default bound where no more specific rule matches the Host, Relation, Target, and level. A specific bound can be zero. An unresolved population leaves a diagnostic.
