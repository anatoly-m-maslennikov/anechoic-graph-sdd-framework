### Prose Claim

Write prose aligned with ASD-STE100. Follow the input intent and applicable instructions. Use one precise Term for each concept consistently throughout the Atom. Use only necessary words and do not restate a point. Use short sentences, paragraphs for explanations, bullets for related points, and numbered lists for ordered steps.

Apply the Atom's applicable Template. Preserve each section's function. When you rewrite an Atom, preserve all of its original meaning, applicability, exact Terms, and references except for changes requested in the input. Keep each actor, condition, exception, limit, and sequence attached to the statements it governs, subject to changes requested in the input.

Compare the source and rewrite in each present section. Use simpler familiar wording when it preserves meaning and keep technical terms needed for precision. Check whether the rewrite changes a condition, a canonical binding, or the spelling or case of a registered reference or literal code token. Read the authoritative Term definition when meaning is in question.

If meaning, applicability, or the applicable Template requirements remain uncertain, retain the affected source wording and escalate to the Actor who can resolve the uncertainty.
