## Summary

Admit implementation-independent Core rules

## Claim

### Prose Claim


Reusable Model and Methodology rules in Ontology Score.


Admit a rule to Ontology Score when it governs a reusable part of the Model or Methodology. Keep it independent of implementation choices outside the entity it governs. a Carrier format, mechanism, portability boundary, **or** external constraint **may** be named **when** that Entity itself is governed, but **must not** become a hidden prerequisite of unrelated Claims. project-specific implementation choices **must not** be imported as reusable methodology authority.
