# Analyze sessions retrospectively for correction signals

ANECHOIC **must** derive self-improvement correction signals by retrospectively analyzing available project sessions **when** proposed by a recurring Project Review **or** initiated on demand; a scheduled Routine **may** perform the analysis **only** **after** explicit operator enablement, **and** reviewed sessions need **not** have invoked `/ca`.
