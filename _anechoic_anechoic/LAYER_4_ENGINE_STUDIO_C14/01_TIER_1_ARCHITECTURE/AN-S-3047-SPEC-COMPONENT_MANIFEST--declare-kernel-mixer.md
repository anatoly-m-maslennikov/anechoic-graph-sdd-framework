## Component Contract

### Own one Project database

#### Guarantee

Admit one Project instance and its Manifest revision before opening
the Workbench database. Keep the connection, projection transactions,
and result snapshots in the Kernel process.

Execute the admitted database operations for that Project over the
declared private API. Reject calls for a different instance. Preserve
committed projection and result state when an operation fails.

#### References

AN-S-3047, AN-S-1363, and AN-T-2947.

### Publish the Console Structure projection

#### Guarantee

Publish Current Components and the Component Seeds in the admitted C93
Structure snapshot. Include parent, Purpose, and exact Manifest reference.
A Seed's embedded Solution opens through its Manifest reference.

Publish the projection on startup, including a retained database, and
refresh it on Structure admission without requiring the Realization Graph.

### Read index diagnostics

#### Guarantee

A plain status call reports index mode. With `include_health` enabled,
report ready, pending, or unavailable from the selected index state.
For a ready index, count indexed Atoms and all ingestion issues. Return
up to 50 issue records. An ingestion issue can coexist with readiness.

### Rebuild the Console projections

#### Guarantee

The `all` selector rebuilds the Project database from source.

#### Formal Claim
