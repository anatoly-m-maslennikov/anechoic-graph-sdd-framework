The refusal events name the reported revision, receipt query ID, or
page identity error. Run and Run & Save use this same display path.
Preserve any result the Project already saved.

The Builder run observes the update, Run, page fetch, and display on the
same path as the general Run action. Its effect labels name the individual
observations collected by the generated case.

Discard is an explicit editor action. A refused save keeps the editor and
pending changes visible. Synchronize with the selected Project through
the Tool API declared by the Manifest.
