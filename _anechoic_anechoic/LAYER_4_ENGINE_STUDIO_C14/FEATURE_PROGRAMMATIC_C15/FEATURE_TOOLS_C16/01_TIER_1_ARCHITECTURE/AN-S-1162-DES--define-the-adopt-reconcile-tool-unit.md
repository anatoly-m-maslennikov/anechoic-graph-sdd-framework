# Define the ADOPT_RECONCILE Tool unit

`ADOPT_RECONCILE` **must** be one Doer Tool owned immediately by `TOOLS` as an `unordered_unit` at Structural level `4`, addressed by `LAYER_2_FRAMEWORK_ENGINE/FEATURE_PROGRAMMATIC/FEATURE_TOOLS/ADOPT_RECONCILE`. Its Delivery place is bound by AN-S-47 and the executable Carrier by AN-S-120. It supports explicit `full`, `continue`, **and** `partial` reconciliation of selected native Implementation against current ANECHOIC authority **and** produces **only** reviewable reconciliation findings **and** non-authoritative CRMED draft proposals **until** the operator separately accepts governed changes.
