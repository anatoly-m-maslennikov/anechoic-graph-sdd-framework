# Summary

Own Provider-Neutral Capability Discovery, Schema, and Dispatch

## Scope

MCP.

## Claim

MCP **must** own the provider-neutral Model Context Protocol discovery, schema, **and** dispatch interface through which an agent invokes active ANECHOIC Tools, receives ACTION_PROMPTS **or** OPERATOR_PROMPTS, **and** starts **or** resumes Workflows. MCP **must not** own Tool behavior, Prompt content, Workflow coordination, Skill procedures, application behavior, **or** agent-host-specific packaging.
