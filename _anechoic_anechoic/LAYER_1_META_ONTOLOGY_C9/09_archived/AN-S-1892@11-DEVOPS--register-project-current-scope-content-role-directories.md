# Register Project Current-Scope Content Role Directories

the anechoic Project **must** use the following administrative Content Role directories directly under `.anechoic_anechoic/` for its current-scope Artifact placement:

- `01_concern/`;
- `02_analysis/`;
- `03_plan/`;
- `04_requirement/`;
- `05_method/`;
- `06_evaluation/`;
- `07_delivery/`;
- `08_implementation/`;
- `09_operations/`.

materialization follows CA-D-296. these administrative directories provide placement; they do **not** become Structural Entities **or** Directory Carriers under CA-D-451.
