## Summary

Define the Spec Proposal Ticket Asset

## Claim

The Spec Proposal Template records a proposed Specification change as a
Ticket Asset. An owning Task or Epic contains the Asset in its companion
`ASSETS/` directory. An unbound Spec Proposal belongs in `__TKT/ASSETS/`.
