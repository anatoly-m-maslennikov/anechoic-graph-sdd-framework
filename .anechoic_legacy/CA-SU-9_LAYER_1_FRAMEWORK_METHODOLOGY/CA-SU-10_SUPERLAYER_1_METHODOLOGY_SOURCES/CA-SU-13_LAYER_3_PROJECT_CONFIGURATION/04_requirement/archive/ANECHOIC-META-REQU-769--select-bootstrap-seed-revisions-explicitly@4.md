# Select Bootstrap Seed revisions explicitly

A ANECHOIC Project MUST apply a Bootstrap Seed update or downgrade only by selecting an identified Seed revision and reconciling its affected Project authority; the selection does not silently rewrite Extension or Project Adaptation authority.
