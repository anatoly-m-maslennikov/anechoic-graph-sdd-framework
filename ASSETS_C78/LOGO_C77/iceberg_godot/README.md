# Anechoic Iceberg

This Godot 4 project renders the medium logo. The iceberg represents the project. Wind carries the person's ideas through the noosphere. The digital technosphere spans interfaces and models near the waterline and microelectronics at depth.

The profile camera places the waterline halfway up the image. A continuous cutaway reveals the interior route and its guardrails. Below the waterline, a glass canopy covers the route. A single smooth line in the ice represents an idea without echoes.

Edit the iceberg profile and the spiral in `iceberg.gd`. The scene uses Avenir Next Demi Bold for the wordmark, with a system sans-serif fallback.

Open `project.godot` and run the project, or export the 500 × 500 PNG with a windowed Godot executable.

```sh
godot --path . --resolution 500x500 -- --render /absolute/path/anechoic_logo_iceberg_medium.png
```
