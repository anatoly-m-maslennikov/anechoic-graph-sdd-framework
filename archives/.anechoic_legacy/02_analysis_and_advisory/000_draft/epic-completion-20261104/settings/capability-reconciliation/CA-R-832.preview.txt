## Summary
Select optional capabilities through Configuration

## Claim

### Prose Claim


the ANECHOIC Framework Instance **must** provide configuration capabilities **to** select, combine, parameterize, **or** disable available optional capabilities **only** within declared configuration boundaries **and** **without** redefining governed meanings.

Where capability selections are applicable, their current values remain under their governing Framework Instance Settings authority; Project Configuration Atoms do **not** become a second owner of those selections.
