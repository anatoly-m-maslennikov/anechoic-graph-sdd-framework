# Define ANECHOIC Direct Route Skill

ANECHOIC Direct Route Skill **means** an Operator-defined Skill that is bound **to** **`=1`** branch **or** leaf registered **in** the ANECHOIC Routing Tree **and** invokes **only** that bound target.
