# Define self-hosted Governance origins

Within the ANECHOIC framework source project, Bootstrap Seed authority, framework authority, **and** applied project Artifacts have internal Governance origin. A distributed ANECHOIC framework source has external Governance origin relative to a consuming project **until** that project establishes its own internal Adaptation authority. Graph relations change **none** of the origins. These origins describe meaning ownership rather than Git authorship, filesystem ownership, **or** byte identity.
