# Admit Project Configuration as a native Implementation Atom

GOVERNANCE expressly admits the human-editable Project Configuration carrier as the native Implementation Atom with externally bound `atom_id: ANECHOIC-I-001` at the registered bootstrap address. The separate decision that establishes how this bootstrap address is discovered remains required when the control root and code roots are not co-located.
