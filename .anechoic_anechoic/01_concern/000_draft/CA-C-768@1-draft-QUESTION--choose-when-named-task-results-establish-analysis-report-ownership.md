## Summary

Choose when named Task results establish Analysis report ownership

## Concern

Should a Task's completion record establish ownership when it names an
Analysis report as a required result?

## Details

Six Tasks identify their required results in named Analysis reports.
Their earliest available revisions record the same results at the
time of the work. The Task instructions require the result but do not
specify an Analysis carrier.

Proposed disposition. Treat the exact named result as ownership.
Place the 19 report revisions beside their corresponding Tasks.
Preserve original Markdown, status, and authored links.

- CA-A-052 → CA-P-070
- CA-A-054 → CA-P-080
- CA-A-055 → CA-P-072
