## Summary

Place each Project Framework Instance inside its Project

## Claim

### Prose Claim


ANECHOIC Framework Instances serving Projects.


the Methodology **and** Tool governance of the ANECHOIC Framework Instance serving a Project **must** reside under that Project's `.anechoic_<project_name>/000_ANECHOIC_framework/` Directory Carrier. this Carrier **must** contain that Project's Methodology Sources **and** Framework Instance Settings. another Project's Framework Instance **or** a repository-shared framework directory **must not** substitute for this Project's instance.

## Details

Applicable Methodology **is** a Projection; its delivered Carriers use the Project's `_projection/` root, **not** this source-governance Carrier.
