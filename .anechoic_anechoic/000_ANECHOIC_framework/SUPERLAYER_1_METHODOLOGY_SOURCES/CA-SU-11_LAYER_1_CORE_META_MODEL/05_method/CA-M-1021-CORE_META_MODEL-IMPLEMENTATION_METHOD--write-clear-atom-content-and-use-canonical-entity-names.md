## Summary

Write clear Atom content and use canonical entity names

## Claim

### Prose Claim

When you write a Claim, name each necessary participant and relation. State each necessary modality, quantity, condition, and boundary. Do not use ambiguous pronouns, anaphora, ellipsis, unstated defaults, or mixed logical groupings. Make the meaning, conditions, and consequences clear.

In authored content, use each entity's exact admitted canonical name and use each governed Term with its authoritative meaning. Resolve the entity and its name before you mention it. Do not infer identity from spelling or substitute a synonym for an admitted name. If a required entity or Term binding is missing, ambiguous, or conflicting, report the uncertainty without inventing a name or meaning.
