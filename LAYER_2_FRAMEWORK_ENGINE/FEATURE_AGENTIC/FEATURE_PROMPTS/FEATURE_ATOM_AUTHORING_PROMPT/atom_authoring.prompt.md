# Create or update an Atom

## Goal

Create or update an Atom from the Actor's input.

## What to do

1. Read the complete input. Use ANECHOIC MCP to read the applicable model and exact source Atom for an update. Resolve semantics from the Atom root → Role property → applicable Role value, and read the Form requirements. As a concise guide, RMED specifies invariants; Operations defines processes. The actual Role definitions govern classification.
2. Write the primary contribution and supporting sections in the declared Role and Form. Preserve source meaning and applicability, including conditions, exceptions, limits, references, and formal or executable content, except for input-authorized changes. Use concise ASD-STE100-aligned prose and consistent, precise ANECHOIC Terms; state each point once. Use short sentences, paragraphs for explanations, lists for related points, and numbered lists for ordered steps.
3. Derive the Summary last from the finalized contribution. Align the Main Subject with the Summary and Claim or other primary section.
4. Apply the internal gate before using the MCP Atom Lifecycle to create or update a Draft. Follow the lifecycle result for a changed Summary or Role and preserve the replacement relationship when a new identity is required. Report the Draft and outcome.
5. Group Atoms with similar Main Subjects when useful, keeping each source and scope distinct. Size batches to fit context. When a subagent nears its context limit, save completed results and assign unfinished Atoms with pinned sources and instructions to a fresh subagent.

## Internal gate

Compare the candidate with the input and, for updates, the exact source in both directions. Check the requirements above. Check that Actors, obligations, permissions, conditions, exceptions, evidence, and sequence retain their scope except for changes authorized by the input. Correct and recheck issues. For unresolved uncertainty, restore the smallest affected original passage and flag the passage and question to the Actor outside Atom prose. A preserved-content Draft may be created, but do not report unresolved work as conforming. For a new Atom missing necessary input, ask the Actor instead of fabricating a claim. Continue independent Atoms.
